# Synthetic media fixtures

`fixtures/av1-aac-frag.mp4` contains one second of a generated test pattern
at 160×120 and 10 fps, with a 440 Hz sine wave at 48 kHz. Its video is AV1
and its audio is AAC. It contains no external media.

Regenerate it from the repository root with the builder's system FFmpeg:

```sh
env LD_LIBRARY_PATH= ffmpeg -v error -nostdin -y \
  -f lavfi -i testsrc2=size=160x120:rate=10 \
  -f lavfi -i sine=frequency=440:sample_rate=48000 \
  -t 1 -c:v libaom-av1 -cpu-used 8 -threads 1 -g 5 \
  -crf 40 -b:v 0 -pix_fmt yuv420p -c:a aac \
  -movflags +empty_moov+frag_keyframe+delay_moov \
  test/fixtures/av1-aac-frag.mp4
```

Clearing `LD_LIBRARY_PATH` lets the system FFmpeg use its matching libraries.
`delay_moov` writes the AV1 configuration after the encoder produces it.

The colored Enhanced RTMP fixtures are generated by
[`ertmp/generate.sh`](ertmp/generate.sh). They combine a generated moving
pattern, a fixed color border, and a sine wave for exact-track playback checks.
